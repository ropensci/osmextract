# Package index

## All functions

- [`bbbike_zones`](bbbike_zones.md) : An sf object of geographical zones
  taken from bbbike.org

- [`geofabrik_zones`](geofabrik_zones.md) : An sf object of geographical
  zones taken from geofabrik.de

- [`get_default_osmconf_ini()`](get_default_osmconf_ini.md) : Get
  default osmconf.ini

- [`oe_clean()`](oe_clean.md) : Clean download directory

- [`oe_download()`](oe_download.md) : Download a file given a url

- [`oe_download_directory()`](oe_download_directory.md) : Returns the
  download directory used by the package

- [`oe_find()`](oe_find.md) : Get the path of .pbf and .gpkg files
  associated with an input OSM extract

- [`oe_get()`](oe_get.md) : Find, download, translate and read OSM
  extracts from several providers

- [`oe_get_boundary()`](oe_get_boundary.md) : Get the administrative
  boundary for a given place

- [`oe_get_keys()`](oe_get_keys.md)
  [`print(`*`<oe_key_values_list>`*`)`](oe_get_keys.md) : Return keys
  and (optionally) values stored in "other_tags" column

- [`oe_get_network()`](oe_get_network.md) : Import transport networks
  used by a specific mode of transport

- [`oe_match()`](oe_match.md) : Match input place with a url

- [`oe_match_pattern()`](oe_match_pattern.md) : Check patterns in the
  provider's databases

- [`oe_providers()`](oe_providers.md) : Summary of available providers

- [`oe_read()`](oe_read.md) : Read a .pbf or .gpkg object from file or
  url

- [`oe_search()`](oe_search.md) : Search for a place and return an sf
  data frame locating it

- [`oe_update()`](oe_update.md) : Update all the .osm.pbf files saved in
  a directory

- [`oe_vectortranslate()`](oe_vectortranslate.md) : Translate a .osm.pbf
  file into .gpkg format

- [`openstreetmap_fr_zones`](openstreetmap_fr_zones.md) : An sf object
  of geographical zones taken from download.openstreetmap.fr

- [`read_poly()`](read_poly.md) :

  Read a `.poly` file.

- [`test_zones`](test_zones.md) : An sf object of geographical zones
  taken from download.openstreetmap.fr
